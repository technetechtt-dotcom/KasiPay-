# KasiPay-

Ekasi Pay — React/Capacitor shop app with an Express API (SQLite locally, optional Postgres via `DATABASE_URL`).

**Setup and runbook:** see [`Ekasi pay/README.md`](Ekasi%20pay/README.md).

**Ops monitoring (separate deployment):** see [`Ekasi pay/ops-dashboard/README.md`](Ekasi%20pay/ops-dashboard/README.md).

PayShap is optional. Launch rails are cash, KasiPay internal wallet, Cash Send, and bank deposit/settlement workflows. See [`Ekasi pay/backend/docs/payment-architecture.md`](Ekasi%20pay/backend/docs/payment-architecture.md).
